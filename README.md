# 🌤️ Aplicativo de Clima - Prática com MVVM, Jetpack Compose, Ktor e Coroutines

Este repositório foi criado com o objetivo de praticar a arquitetura **MVVM** e o uso das tecnologias **Jetpack Compose**, **Ktor** e **Kotlin Coroutines** na construção de um aplicativo de previsão do tempo.

## 🚀 Tecnologias Utilizadas

- **MVVM (Model-View-ViewModel)**: Arquitetura que separa responsabilidades e facilita testes e manutenibilidade.
- **Jetpack Compose**: Toolkit moderno da UI para Android que facilita a criação de interfaces de forma declarativa.
- **Ktor**: Cliente HTTP usado para realizar requisições à API de clima.
- **Kotlin Coroutines**: Para gerenciar operações assíncronas de forma simples e eficiente.

## 🌦️ Funcionalidades do Aplicativo

- Consulta do clima atual de uma cidade.
- Interface reativa e declarativa com Compose.
- Requisições HTTP utilizando Ktor para buscar dados de previsão do tempo.
- Gerenciamento de estados com ViewModel e StateFlow.
- Boas práticas com coroutines para chamadas assíncronas e tratamento de erros.
